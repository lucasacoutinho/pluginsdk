# Portable features in a Claude Linux project

A private Claude Code 2.1.304 candidate passes a complete portable v2 lifecycle in project scope on Linux. One project uses the plugin's MCP server, hooks and agent; a second project sharing that home remains unaffected. This checkpoint keeps production profiles unchanged. The subsequent [recovery qualification](portable-features-project-recovery-acceptance.md) and [stdio-only qualification](portable-project-stdio-linux-acceptance.md) enable both portable formats for this production project profile.

The [project design](portable-features-project-design.md) keeps the existing definition, build and destination interfaces. This experiment changes one private profile row. All 183 production source files retain the [automatic feature build checkpoint](portable-feature-defaults-acceptance.md)'s hashes.
