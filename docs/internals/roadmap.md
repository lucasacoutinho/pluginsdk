## Deferred and external work

CI, package-consumer checks, full release gates and publication remain explicitly deferred. Keep the repository private and MIT. Lucas has authorized isolated commits and private PR landing, coordinated with the launch-review session. Landing preserves the shared index and HEAD. Release tags and deployment remain deferred.

macOS has no available host. Grok native testing and third-party authentication remain deferred. Meta Muse has no verified management contract. Windows source symbolic-link qualification needs privileges unavailable on this host.

Organization workspace administration, audiences and deployed reader/admin/revocation acceptance need actual workspace, identity-provider and service inputs. ChatGPT and Claude Desktop/web are separate targets; Codex evidence does not qualify them. Plugin/MCP source management, hosting, more hook events and more agent controls remain future scope.

The [launch plan](launch-plan.md) keeps these dependencies separate from actionable completion. Deferred items are not completed features. Formal TypeScript refinement remains unproved; Lean model proofs and passing oracle comparisons are reported separately.
