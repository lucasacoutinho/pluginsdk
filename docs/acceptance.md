# Alpha acceptance

The initial profile qualifies Linux, Node 24 or later, Claude Code 2.1.304 and Codex CLI 0.163.0. Native tests create temporary homes and use a loopback MCP fixture. They perform no model turns or provider authentication.

Run `npm run check` for the portable gate and `npm run test:native` for native acceptance, including the installed-package pass. The former contains 60 Vitest tests; native Vitest contains another 39. Native CLI commands require both exact qualified binaries. `npm run test:package` produces `.artifacts/pluginsdk-0.1.0-alpha.0.tgz` and its SHA-256 file. Its declarations check both `ReviewedPlan` repair callers and existing `ReadyPlan` callers. The lstack pilot is a separate compiled acceptance harness; its source-path-dependent invocation is in the pilot record.

## Limits

The Lean proofs cover pure policy. Filesystem truth, hash implementations, process quiescence and durable storage remain checked I/O assumptions. Process-kill tests do not simulate machine power loss. SDK locks coordinate SDK writers; arbitrary external host edits are outside that lock.

The [organization authorization model](authorization-design.md) proves identity, freshness, exact tool grants and required restrictions over supplied evidence. It does not establish that a token was verified or that a service enforces its result. The [catalog model](catalog-design.md) proves immutable admission and exact selection through its pure transitions. Catalog persistence, artifact verification, workspace distribution, existing-service adapters and end-to-end revocation latency remain open.

Claude's exposed inspection commands establish MCP connection and tool discovery. The harness does not claim a Claude model-driven tool call. Codex's direct app-server tool call needs no model turn. Neither fixture proves third-party OAuth or credential availability.

Other native versions, non-Linux capture/installation and Codex project scope are unqualified. Grok Bot and Meta Muse return `DestinationUnsupported`; [host research](host-research.md) records the missing contracts. ChatGPT, Cursor and organization management remain the planned [organization design](organization-design.md). A partial native recipe can remain pending and uncertain. Explicit reviewed repair handles qualified absence and orphaned marketplaces; automatic retry or rollback is outside the alpha.

PluginSDK is licensed under [MIT](../LICENSE) and kept in the [private repository](https://github.com/lucasacoutinho/pluginsdk). The package has `private: true`; public npm publication is deferred at the user's request.

Private CI runs the full portable gate from a fresh checkout and `npm ci`. The repository-scoped ephemeral WSL runner uses the installed Lean toolchain; the project's pinned version and complete axiom audit still run through `npm run check`. The runner deregisters after one job. The [Actions history](https://github.com/lucasacoutinho/pluginsdk/actions/workflows/check.yml) records each checked commit; each expansion needs its own successful run. Hosted jobs remain blocked before execution by GitHub's account billing/spending-limit diagnostic.
